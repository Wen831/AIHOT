
【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：球队名 / 球员名 / 教练名 / 赛事名 / 俱乐部名。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是口号 / 悬念 / 没信息量的 teaser（如 "Official"、"Here we go"、"官宣"、"重磅"）时，结合【来源】和正文把主体补进标题。例：原标题 "Here we go" + 来源与正文明确是罗马诺报道某球员转会 → "罗马诺：某球员转会达成协议"。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体球员时，用上位词（如"某豪门中场"）兜底，绝不凭"行业常识"编一个具体球员 / 金额 / 比分。
5. 原标题表达的【文章类型和核心动作】是硬边界：分析 / 复盘 / 战术解读 / 采访 / 盘点这类解释与评论标题，中文标题必须保留这个类型；不能因为正文谈到一个已经发生的比赛或转会，就改写成“官宣 / 签约 / 击败”。只有原标题明确宣布了官宣、签约、解约或比赛结果，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的球队、球员、赛事名。
   例：原标题 "Why Real Madrid's midfield controlled the final" → "皇马中场如何掌控决赛"，不能写成 "皇马夺得欧冠"。
   例：原标题 "五大联赛冬窗最值得关注的十名球员" + 来源明确是懂球帝 → "懂球帝盘点：冬窗值得关注的十名球员"，不能只写成缺主体的 "十名球员值得关注"。
