# 词表目录（由使用者自行部署）

本模块在分析管线第一步（模型预筛之前）对标题、摘要、正文做本地词表检查：命中且不在豁免名单的条目直接按 BLOCK 处理（`processing_state=blocked`），不再进入任何模型调用——避免供应商内容审核在管线中段拦截造成 failed 报错。

**本目录不内置任何词表文件**，格式约定如下：

| 文件 | 作用 |
|------|------|
| `*.txt`（除 whitelist） | 词表，一行一词；`#` 开头为注释行；文件名建议 = 来源仓库/类目（便于追溯），按文件名顺序加载 |
| `whitelist.txt` | 豁免词表（同格式）。某次命中的词全部在豁免名单内则放行 |

- 词表内容 UTF-8 编码；英文不区分大小写
- **词表打进 Docker 镜像**：新增/修改词表后需 `docker compose up -d --build` 重建生效（改词表无需改代码）
- 命中词目**不会**写入数据库或日志：analysis 记录只存 `lexicon:title|summary|body`（命中字段位），可在后台按 `reason LIKE 'lexicon:%'` 统计拦截占比
- 词表为空时模块挂载但不拦截（启动日志有一行提示），不影响任何现有行为
- 调参闭环：漏拦（仍出现模型侧拦截）→ 补词；误拦（blocked 条目实际正常）→ 删词或进 whitelist，rebuild 后对新采集生效；存量误拦条目可后台重排（换新 attemptTag 强制重跑）
